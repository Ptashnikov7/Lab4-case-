## Інструкція із запуску програми у контейнері Docker

### 1. Створення Docker-мережі (Docker network)
Перед запуском контейнерів створимо ізольовану мережу, як вимагається у завданні:
```bash
docker network create lab-net
```

### 2. Збірка Docker-образу
Для створення локального Docker-образу виконайте команду в терміналі (у кореневій папці проекту):
```
docker build -t lab2-model .
```

### 3. Запуск контейнера з налаштуваннями (Порти, ENV, Network)
Для запуску контейнера з прокиданням портів, передачею змінних середовища (обрано варіант MODE="eco" для парного номера у списку) та підключенням до мережі, виконайте:
```
docker run -d -p 5000:8000 --network lab-net -e STUDENT_NAME="Пташников Василь" -e GROUP="АІ-235" -e MODE="eco" --name lab2-container lab2-model
```
Опис параметрів запуску відповідно до завдання:
-d — запуск контейнера у фоновому режимі (detached mode).

-p 5000:8000 — прокидання портів (зовнішній порт 5000 перенаправляє запити на порт сервісу 8000).

--network lab-net — підключення контейнера до створеної Docker-мережі.

-e STUDENT_NAME="...", -e GROUP="...", -e MODE="..." — передача обов'язкових змінних середовища.

--name lab2-container — унікальне ім'я контейнера за ТЗ.

4. Перевірка роботи сервісу
http://localhost:5000
