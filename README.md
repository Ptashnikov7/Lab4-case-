## Інструкція із запуску програми у контейнері Docker

### 1. Збірка Docker-образу
Для створення локального Docker-образу виконайте команду в терміналі (у кореневій папці проекту):
```bash
docker build -t computational-service:v1 .
```
### 2. Запуск контейнера
Для запуску контейнера з налаштуванням портів та змінних середовища виконайте:
docker run -d -p 8080:8000 -e NEWTON_X0="5.0" --name my_service_container computational-service:v1

Опис параметрів запуску:
-d — запуск контейнера у фоновому режимі (detached mode).

-p 8080:8000 — прокидання портів. Зовнішній порт 8080 вашого комп'ютера перенаправляє запити на порт 8000 всередині контейнера.

-e NEWTON_X0="5.0" — задання змінної середовища, яка визначає початкове значення для обчислювального методу.

--name my_service_container — унікальне ім'я для запущеного контейнера.

### 3. Перевірка роботи сервісу
Після запуску контейнера сервіс стає доступним у браузері за адресою:
http://localhost:8080
